# 潮镇多人在线游戏 — 操作指南

## 一、项目结构

```
multiplayer-game/
├── server.js          # 服务器主程序（HTTP + WebSocket）
├── game-engine.js     # 游戏引擎（所有游戏逻辑，纯服务端）
├── constants.js       # 游戏常量（7个家族、7幕、命运牌等）
├── package.json       # 依赖配置
├── Dockerfile         # Docker 部署文件
├── railway.json       # Railway 部署配置
└── public/            # 前端页面
    ├── index.html     # 大厅页面（创建/加入房间）
    ├── game.html      # 游戏主页面
    ├── game.css       # 样式
    └── game-client.js # 前端客户端（WebSocket + 渲染）
```

## 二、本地运行

```bash
cd multiplayer-game
npm install
node server.js
```
浏览器打开 `http://localhost:3000`

## 三、部署到 Railway

1. 注册/登录 [Railway](https://railway.app)（可用 GitHub 账号登录）
2. 点 "New Project" → "Deploy from GitHub repo"
3. 上传本项目代码到 GitHub 仓库，连接该仓库
4. Railway 会自动检测 Dockerfile 并构建
5. 部署完成后，在 Settings → Networking → Generate Domain 获取公网 URL
6. 访问该 URL 即可使用

## 四、游戏操作流程

### 讲师（导师管理端）

1. 打开网站首页，点 **「创建房间」**
2. 系统生成一个房间号（如 `CZ-ABCD`）和 8 个链接：
   - **导师管理端链接**（1个）→ 点击进入，可查看所有学员实时状态
   - **学员1~7号链接**（7个）→ 分别发给 7 位学员
3. 导师界面功能：
   - 实时查看每个学员的资产配置、消费选择、危机应对
   - 查看进度面板（谁完成了哪一幕）
   - 查看动态事件流（每个操作的实时记录）
   - 控制游戏节奏（进入下一幕、返回上一幕、重置游戏）
4. **把 7 个学员链接分别发给 7 个人，每人点自己的链接进入游戏**

### 学员（7个家族）

1. 收到导师发的链接，点击进入
2. 自动分配家族角色（家族1~7，各自不同）
3. **每人只能看到自己的数据**，看不到其他人的资产、选择
4. 按导师引导完成 7 幕：
   - 第一幕：500万资产配置
   - 第二幕：消费选择
   - 第三幕：痛苦账单（命运牌）
   - 第四幕：危机应对
   - 第五幕：债务处理
   - 第六幕：合作项目
   - 第七幕：宝藏计划
5. 每一步选择实时同步到导师管理端

### 数据隔离机制

- 每个学员通过 WebSocket 连接时携带 `role=family0` ~ `family6`
- 服务器只下发该学员自己家族的数据，其他家族数据不发送
- 导师端 `role=host` 可以看到所有 7 个家族的完整数据
- 所有游戏逻辑（随机数、计算）在服务器端执行，客户端无法作弊

## 五、技术架构

| 组件 | 说明 |
|------|------|
| 服务器 | Node.js + ws 库，HTTP 静态文件 + WebSocket 同一端口 |
| 房间系统 | 每个房间独立游戏状态，互不干扰 |
| 状态同步 | 每次操作后服务器广播完整状态给房间内所有人 |
| 数据隔离 | 学员只收自己家族数据；导师收全部数据 |
| 随机数 | 全部在服务端执行（命运袋、危机减损、宝藏收益等） |
